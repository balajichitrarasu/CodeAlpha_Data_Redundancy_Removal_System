# CodeAlpha Data Redundancy Removal System

## Project Overview
This project was developed as part of the Cloud Computing Internship at CodeAlpha.

The system identifies duplicate and redundant email data, validates entries, prevents duplicate storage, and maintains database efficiency.

## Features
- Universal Email Validation
- Duplicate Data Detection
- False Positive Handling
- Search Email Function
- Delete Email Function
- Statistics Tracking
- Timestamp Logging
- Database Management

## Technologies Used
- Python
- Regular Expressions (Regex)
- File Handling
- GitHub

## How To Run

```bash
python app.py
```
